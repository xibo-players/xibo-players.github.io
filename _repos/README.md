# `_repos/` — split between active and dormant subdirs

**R2 is the source of truth for published packages and repodata** as
of 2026-04-17. This directory was the pre-R2 layout for per-package
repos and is now split:

## ACTIVE — `xiboplayer-release/`

Build sources for the `xiboplayer-release` repo-config package
(ships the `.repo` file + GPG key). Consumed by
`.github/workflows/build-release-pkg.yml`:

- `xiboplayer-release.spec`, `build.sh` — RPM build
- `build-deb.sh`, `debian/` — DEB build
- `xiboplayer.repo`, `xiboplayer.sources`, `copr-keyd.repo` — shipped
  by the built package
- `RPM-GPG-KEY-xiboplayer`, `xiboplayer.gpg` — public GPG keys
- `xiboplayer-release_*.deb` — pre-built artifacts kept in-tree for
  historical reference (the workflow rebuilds these on each tag).

This subdir is load-bearing — do not move or rename without updating
`build-release-pkg.yml` paths.

## DORMANT — placeholders, no workflow references

The following subdirs hold stale repodata from before R2 became the
source of truth. **They are not referenced by any workflow** (verified
2026-05-30 via `grep -rn '_repos/' .github/`):

- `arexibo/`
- `xibo-kiosk/`
- `xiboplayer-chromium/`
- `xiboplayer-electron/`
- `xiboplayer-kiosk/`
- `xibo-players.github.io/`

Each contains only `rpm/fedora/**/repodata/*.xml.zst` and
`repomd.xml` files generated by `createrepo_c` against package sets
that no longer exist in-tree. Pending a separate audit they are safe
to remove from the working tree; kept tracked for now to avoid
mixing cleanup with the dormant-dir documentation pass.

See also: `rpm/README.md` for the top-level `rpm/` directory.
